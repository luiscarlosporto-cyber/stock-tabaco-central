Importante

O pacote contém a aplicação e o catálogo inicial. Para funcionar de forma centralizada em vários telemóveis, é necessário criar o projeto Supabase, aplicar o esquema SQL fornecido no pacote e configurar as credenciais. O alojamento HTTPS é necessário para usar a câmara.
