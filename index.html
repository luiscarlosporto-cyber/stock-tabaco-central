Encomenda a partir das vendas

Carregue o CSV de vendas exportado do software Repsol (o mesmo relatório de vendas por artigo, de uma semana). A app calcula a encomenda do fornecedor escolhido (o tabaco para uma semana; o tabaco aquecido e as recargas até à encomenda seguinte, de segunda a quinta 3 dias e de quinta a segunda 4 dias), com +10% nos 10 mais vendidos, e deixa-a à espera de aprovação, como no envio do stock.

Configuração da base de dados central

A ligação é autenticada. Nunca coloques uma chave service_role nesta aplicação.

Estado: modo local neste dispositivo. Sem configuração, não existe sincronização entre telemóveis.

Importante

O pacote contém a aplicação e o catálogo inicial. Para funcionar de forma centralizada em vários telemóveis, é necessário criar o projeto Supabase, aplicar o esquema SQL fornecido no pacote e configurar as credenciais. O alojamento HTTPS é necessário para usar a câmara.
